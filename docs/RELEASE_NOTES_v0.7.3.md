适用于 Windows x64、Euro Truck Simulator 2 1.62.x 和官方 Coaches DLC。

## 功能

- 德、英、中、日四语广播，支持单语或四语依次播放。
- 欢迎、下一站、即将到站、终点四类广播，可自定义快捷键。
- 通过 SCS SDK 读取当前客运线路，游戏内面板支持试听、停止、音量、语言和自动广播设置。
- 完整包提供 398 个城市或地点 ID 的四语站名，以及 416 条标准地图站点或观景点坐标。
- 音频和坐标随包提供，日常使用可离线运行。

## 0.7.3 更新

- 途经站距离加入游戏当前地图比例换算，修正此前直接使用世界坐标距离导致播报过早的问题。
- 终点预告优先使用游戏导航剩余路程，并结合已知站点坐标核验。
- 补齐四语终点预告 WAV。某个语种缺少预告时，尝试回退到该语种的「即将到站」。
- 日志增加触发阈值、原始直线距离、地图比例和音频回退信息。

## 升级步骤

1. 退出 ETS2。
2. 将升级包 `01-Game` 内的 `bin` 合并到游戏安装目录，覆盖两个 CoachAnnouncer DLL。
3. 将 `02-LocalAppData` 中的 `CoachAnnouncer` 合并到 `%LOCALAPPDATA%`。请同时合并 `audio`，终点预告在这里。
4. 启动游戏，核对自动到站开关和距离阈值。

已有自定义坐标表时，可只更新音频，保留自己的坐标文件。

默认广播按键为 Num1、Num2、Num3、Num5。面板默认通过左 Ctrl + 左 Shift + F8 开关。

## 已知限制与验证

途经站采用按地图比例换算的直线距离，绕行、匝道、高架及比例切换会影响播报时机。末段导航目标应保持为客运终点。地图 Mod 移动后的站点需匹配对应坐标。

0.7.3 已通过 Windows x64 构建、五项本地模拟测试和发布载荷核对，已收到当前版本可用的实机反馈。EXE 向导、全部地图站点以及其他插件组合仍需更多实机验证。
